# Python laba 6

Приложение представляет собой десктопный трекер задач и учета выполненных дел (Task Tracker). Проект включает в себя полноценный графический интерфейс для управления задачами, хэширование учетных данных, безопасную авторизацию и двухфакторную аутентификацию (2FA) через Telegram-бота.

## ✨ Основные возможности

*   **Учет и отслеживание задач:** Создание, архивация и менеджмент созданных дел пользователя.
*   **Интуитивный GUI (`MainMenu2.py`):** Графический интерфейс для взаимодействия с базой данных и списками задач.
*   **Защищенная авторизация (`Hash.py`, `checkpassword.py`):** Безопасный вход в систему. Пароли хэшируются и проверяются на сложность перед сохранением.
*   **Двухфакторная аутентификация через Telegram (`tg_bot.py`):** Генерация временных кодов для подтверждения входа или выполнения критических действий.
*   **Локальное хранилище (`account.db`):** Использование SQLite для надежного хранения учетных записей и связанных с ними списков дел.

## 📁 Структура проекта

```text
│
├── account.db          # Локальная база данных SQLite (пользователи и дела)
├── temp_codes.json     # Хранилище временных OTP-кодов для Telegram-авторизации
│
├── MainMenu2.py        # Главный файл графического интерфейса (Task Tracker GUI)
├── Hash.py             # Модуль хэширования паролей и конфиденциальных данных
├── checkpassword.py    # Валидатор паролей на соответствие политикам безопасности
├── logpass.py          # Логика обработки и сверки пар логин/пароль
│
├── database_setup.py   # Скрипт первоначальной инициализации таблиц базы данных
├── creatyeobject.py    # Фабрика/модуль создания объектов задач и пользователей
├── archive.py          # Модуль для работы с архивом выполненных дел
│
├── tg_bot.py           # Telegram-бот для отправки одноразовых кодов (2FA)
└── tg_form.py          # Логика взаимодействия основного приложения с ботом
```

## 🛠️ Требования и зависимости

Для работы приложения необходим **Python 3.9+**. 
Перед запуском установите библиотеки для работы с GUI и Telegram API (PyQt5 / telebot):


## 🚀 Инструкция по запуску

### Шаг 1. Настройка Telegram-бота
1. Создайте бота у [@BotFather](https://t.me) в Telegram и получите токен.
2. Пропишите полученный токен в файле `tg_bot.py`.

### Шаг 2. Инициализация базы данных
Перед первым запуском необходимо создать структуру таблиц для пользователей и дел:
database_setup.py

### Шаг 3. Запуск Telegram-бота
Запустите бота в отдельном окне терминала для обеспечения отправки кодов:
tg_bot.py

### Шаг 4. Запуск приложения задач
Запустите главный файл графического интерфейса:
 MainMenu2.py
